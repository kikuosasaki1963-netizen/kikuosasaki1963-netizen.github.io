アルケミー株式会社（以下「当社」）は、ウェブアプリ「賃管士 条文で解く」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 当社が収集する情報

本アプリは、LINE でログインした方だけがお使いになれます。ログインと利用期限の管理のために、当社は次の情報を当社のサーバーに保存します。

保存するもの 内容
LINE の利用者 ID LINE が本アプリに対して発行する、利用者ごとの識別子
利用者番号 当社が割り振る8文字の英数字。利用期限を過ぎたときの画面に表示し、延長のご連絡の際に使います
利用期限と延長の記録 利用期限を延長した場合の、延長前と延長後の期限・延長した日時・理由・対応した担当者の名前
ログインの日時 最初にログインした日時と、最後にログインした日時
ログイン中の状態 ログインした日時・有効期限・ログアウトした日時。本アプリが端末に渡す合言葉（トークン）は、元に戻せない形（ハッシュ）でしか保存しません
LINE から受け取る鍵 LINE 公式アカウントの友だちかどうかを LINE に確かめるための鍵（アクセストークン・リフレッシュトークン）とその有効期限、および友だちであることを最後に確かめた日時。鍵は暗号化して保存します
ログインの途中の一時的な情報 LINE のログイン画面へ移る前と後を結び付けるための使い捨ての値（最長10分有効）と、ログインの直後に本アプリの画面へ渡す使い捨ての番号（最長60秒有効・元に戻せない形で保存）

当社は、次の情報を保存しません。

  • LINE の表示名・プロフィール画像（ログインの際に LINE から届くことがありますが、保存しません）
  • 氏名・メールアドレス・電話番号・住所その他の連絡先
  • 位置情報、カメラ、マイク、写真、連絡先、カレンダーの情報
  • 広告識別子その他の端末を識別する情報

本アプリは Cookie を使いません。アクセス解析ツール・広告、および第三者が提供する解析用・広告用のソフトウェア（SDK）は組み込まれていません。

2. 利用の目的

第1項の情報は、次の目的にだけ使います。

  • ログインした方を見分けるため
  • LINE 公式アカウント「ありいえ」（@007jhdxw）の友だちであることを確かめるため（ログインのたびと、ログインの後は24時間に1回まで）
  • 利用期限を判定し、延長のご連絡に対応するため
  • ログインの仕組みを、なりすましや不正な利用から守るため

3. 端末の中に保存される情報

本アプリは、次の情報を利用者の端末の中（端末内の保存領域 IndexedDB）に保存します。

保存するもの 内容
ログインの状態 ログインし直さずに使えるようにするための合言葉（トークン）と、その有効期限・利用期限。本アプリが当社のサーバーに問題を求めるたびに、ログインの確認のため当社のサーバーへ送ります
問題の束 当社のサーバーから受け取った予想問題（通信の無いところでも利用期限まで解けるようにするため）
解答の記録 どの問題に、どの選択肢で答えたか、および答えた日時
復習の予定 間違えた問題を次にいつ出し直すかの計算結果
解きかけの記録 途中まで解いた問題と、そこまでの解答

解答の記録・復習の予定・解きかけの記録は、端末の外に送信されることはありません。当社はこれらを閲覧することも、取得することもできません。 本アプリには、解答の記録を将来サーバーへ送るための仕組みが用意されていますが、送り先を設定しておらず、現在この仕組みは動作していません。この設定を行う場合は、行う前に本ポリシーを改めます。

端末の保存領域を使えない場合（ブラウザのプライベートモード等）は、ログインの状態と問題の束を端末の記憶領域の中だけに置き、画面を閉じるか再読み込みすると消えます。

4. LINE とのやり取り

  • ログインの際、利用者は LINE のログイン画面へ移り、LINE の画面で本アプリとの連動に同意します。同意の後、LINE から当社のサーバーへ、LINE の利用者 ID を含む情報と第1項の鍵が渡ります。
  • 当社のサーバーは、友だちであることを確かめるため、第1項の鍵を LINE に送ります（ログインのたびと、ログインの後は24時間に1回まで）。鍵の有効期限が切れたときは、鍵を更新するためにも送ります。
  • LINE での情報の取り扱いは、LINEヤフー株式会社が定めるプライバシーポリシーに従います。

5. 情報を置く場所

当社は、次の事業者のサービスを使って本アプリを動かしています。

用途 サービスと場所
当社のサーバー Google Cloud（東京）

6. 情報の第三者への提供

当社は、法令に基づく場合を除き、第1項の情報を第三者に提供しません。

第4項の LINE とのやり取りのほかに、解析事業者・広告事業者その他の第三者へ利用者の情報を渡す仕組みを、本アプリは持ちません。

7. 保存の期間

  • 第1項の情報は、本アプリの提供を続ける間、保存します。利用期限を過ぎた後も、延長のご連絡に対応できるよう保存します。
  • ログインの途中の一時的な情報は、有効期限（最長10分・60秒）を過ぎると使えなくなり、その後のログインの受付の際に消去します。
  • 当社のサーバーの通信の記録は、30日で自動的に消去されます。

8. 保存された情報の削除

  • 画面の末尾の「ログアウト」を押すと、端末のログインの状態と問題の束を消し、当社のサーバーでもそのログインを使えなくします。
  • 第3項の解答の記録・復習の予定・解きかけの記録は、ブラウザの設定からこのサイトのデータを削除すると消えます。
  • 当社のサーバーに保存した第1項の情報の開示・訂正・利用の停止・消去のお求めには、個人情報の保護に関する法律に従って対応します。第13項の窓口へご連絡ください。ご本人であることを確かめたうえで対応します。

9. 同意の撤回

LINE のログイン画面での同意は、LINE アプリの設定から本アプリとの連動を解除することで撤回できます。解除した後は、当社のサーバーは友だちであることを LINE に確かめられなくなり、本アプリを使うにはログインし直す必要があります。当社のサーバーに保存した情報の消去をお求めの場合は、第8項のとおりご連絡ください。

10. 安全のための取り組み

本アプリと当社のサーバーの間、および当社のサーバーと LINE の間の通信は暗号化しています。第1項のとおり、LINE から受け取る鍵は暗号化し、ログインの合言葉と使い捨ての番号は元に戻せない形でのみ保存します。

本アプリは賃貸不動産経営管理士試験の学習を目的としており、お子様を対象とした機能を持ちません。当社は年齢を収集しません。
